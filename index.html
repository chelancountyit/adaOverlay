Click the circular navy accessibility icon in the bottom-right corner—or use the JavaScript API buttons below—to launch the Accessibility Adjustments overlay modeled after co.chelan.wa.us.

Motion & Visual Trigger Test

Toggle Seizure Safety or Stop Animations inside the overlay to pause this continuous CSS animation immediately.

Programmatic JavaScript Triggering

In CMSAdmin 2.0 (or any website), you can call window.ADAOverlay methods from any custom button, menu item, or script: 

// Drop-in script on any website:
<script src="ada-overlay.js" defer></script>

// Or invoke via JavaScript anywhere:
ADAOverlay.open();
ADAOverlay.setProfile('lowVision', true);
ADAOverlay.reset();
